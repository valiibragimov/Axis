Дата и расчётные условия сохраняются в `acceptanceCriteria`. Ранее сохранённые проверки читаются без миграции. Для новых повторных проверок `repeatOf` содержит ID исходной записи в том же модуле и объекте. Старые записи без этого поля не получают выведенный из догадки тип проверки. При откате старый клиент игнорирует новые поля и не выполняет новые динамические расчёты армирования.

При частичном импорте IFC неизвестные координаты и оси остаются пустыми. Такой импорт возможен через подтверждение в рабочей области и защищён от замены опубликованной модели с тем же идентификатором. Серверная точка импорта требует полный набор данных размещения.
