# Бренд Axis и совместимость

Axis — название продукта на русском и английском языках. Используйте `Axis` в интерфейсе, метаданных PWA, документации, заголовках API и новых отчётах. Репозиторий: https://github.com/valiibragimov/axis.

Переименование не требует миграции данных. Аккаунты, проекты, проверки и версии документов сохраняют свои идентификаторы и исходные свидетельства. Сохранённые тексты и PDF остаются неизменными; новые отчёты используют бренд Axis и метаданные PDF.

Следующие технические имена со старым названием сохранены намеренно:

- `tehnadzor_repeat_control` и IndexedDB `tehnadzor-bim-viewer`: сохраняют доступ к данным браузера.
- Префикс кеша service worker `tehnadzor-`: сохраняет жизненный цикл кеша; сборка обновляет хеш содержимого.
- Строки со старым названием в тестах совместимости и списках запрещённых производственных настроек: продолжают проверять сохранённые данные и выявлять старую конфигурацию.

Инженерный термин «технадзор» обозначает роль или вид контроля, а не продукт. Он сохраняется в учебных материалах и реквизитах документов.

Идентичность репозитория GitHub, история, issues, права и workflows сохраняются после переименования. Адреса Firebase Hosting не зависят от имени GitHub и не переименовываются при смене бренда.

## Firebase Hosting

[Axis](https://axisxyz.web.app) работает на сайте Hosting `axisxyz` в существующем проекте Firebase `tehnadzor-online`. Используйте ID проекта, ID веб-приложения и бакет Storage этого проекта. Для рабочей сборки задайте `FIREBASE_WEB_AUTH_DOMAIN=axisxyz.web.app`. Добавьте домен в Firebase Authentication, а в действующем OAuth-клиенте Google разрешите источник `https://axisxyz.web.app` и URI переадресации `https://axisxyz.web.app/__/auth/handler`.

Соберите приложение командой `npm run build` и опубликуйте только Hosting командой `firebase deploy --only hosting:axisxyz --project tehnadzor-online`. Firebase сохраняет стандартный сайт и его домены. Сессия входа и локальный кеш привязаны к адресу, поэтому на новом сайте войдите в существующий аккаунт.

Стандартный сайт постоянно перенаправляет посетителей на Axis. Настройки переадресации находятся в `firebase.legacy-hosting.json`. Чтобы обновить их, после сборки выполните `firebase deploy --only hosting --config firebase.legacy-hosting.json --project tehnadzor-online`.
